## Features
- AI/ML routing decisions (TensorFlow)
- Mathematical load optimization
- NGINX failover protection
- Real-time web dashboard

## Installation
```bash
git clone https://github.com/TAnusara/AI-POWERED-HYBRID-LOAD-BALANCER.git
cd AI-POWERED-HYBRID-LOAD-BALANCER
pip install -r requirements.txt
```

## Usage
```bash
# Start backend servers
python3 server1.py & python3 server2.py

# Start load balancer
python3 hybrid_lb_simple.py

# Access dashboard at:
http://localhost:5000
```
